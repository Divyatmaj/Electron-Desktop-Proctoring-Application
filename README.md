# Athena Proctoring

A desktop application for exam proctoring, built with React, Vite, and Electron.

## Features

- Pre-exam readiness checklist
- Desktop application foundation
- React-based user interface
- Isolated Electron preload bridge

## Tech Stack

- JavaScript
- React
- Vite
- Electron
- CSS
